# DIA-006 — Call screen + code display
**Spec:** §10.1–10.3 (v0.38)
**Goal:** pitch-type row (team-config stub: 4 types, no per-type color — the accent marks the selected
one) + call-zone grid over §10.1's canonical 25 cells, with the team layout as a *grouping* of those
cells and a per-type callable subset; tap-tap → pending call + HUGE code (≥120pt) from a stub
WristbandCard (grid-coordinate model, k=4); re-roll swipe; call replacement before commit.
**Accept:** widget tests: two taps produce pending call w/ correct centroid + a valid code for that call;
re-roll returns different code same call; the grid's geometry does not move between pitch types, only
which cells are callable; any point resolves to exactly one zone; nothing persists to the event store
until pitch entry (DIA-007).
**Out of scope:** card generation/print (M2), decoys, offense grid, per-type *grouping* overrides
(subsets only), onboarding. No chase-specific gesture — v0.38 removed it, since all 25 cells are
directly callable.
