**Spec:** everything above
**Goal:** end-to-end integration test + manual script: score a full half-inning (provided script: 14 pitches,
incl. Play #1, a walk, a K, an unknown pitch + CountCorrection, one undo) entirely offline on an emulator.

**Accept:** automated test green in CI; Mark performs the manual script on a real tablet and signs off.
Retro doc: docs/m1-retro.md with friction notes → they become M2 tickets.

**Carried from DIA-008d's no-writer audit (2026-08-25): write the `InningHalfStart` snapshot.**
§7's checkpoint — "so mid-game app restarts and multi-game stat queries don't replay from zero;
snapshots are cache, never truth" — is **fully built except for a writer.** `GameStateProjector`
already takes the fast path when one exists and already rejects it when a later event `corrects`,
voids, or `effectiveAfter`-anchors something at or before the boundary, with tests including the
backdated insert. Nothing embeds one, so every projection is a full replay from genesis.

It lands here because it has nowhere else to live: **nothing emits `InningHalfStart` after the
bootstrap** — the inning never flips, which is this ticket's job — and that event is the only place
with a `GameState` worth checkpointing. When the flip lands, embedding the fold's current state is a
couple of lines and the guard is already written.

Nothing is broken meanwhile: the fallback *is* the truth path, so absent snapshots only mean the slow
route. Worth one check when it goes in — that a snapshot is never trusted across a `CountCorrection`,
which is a normal forward event rather than a correction of an earlier one, so it should be safe by
construction but is where "cache, never truth" would bite hardest.

**Carried from DIA-008's stream audit (v0.43):** `BatterOutcome.atBat` exists but nothing consumes
it yet — the box-score projection this ticket renders is the first thing that should, and it needs
**at-bats and plate appearances as separate totals** (AVG divides by the first, OBP by the second).
Sacrifices are handled (§13.6): the fly derives, the bunt is a stored judgment, and neither is an
at-bat — so the box line needs both denominators to be right the first time.
