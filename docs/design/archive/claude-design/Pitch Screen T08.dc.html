Turn 08 · Call, relay, record
The call includes a spot, so the code can exist
Three steps, renamed to what they are: 8A call pitch — type and called zone, since the code is a type-and-spot pair and can’t be looked up without both; 8B relay code — a check you tick when you’ve shouted it, not a gate that hides the field; 8C record location — where it actually went, with the called zone still drawn as a dashed box so intent and result sit on the same picture. The code card stays pinned top-left through step 3 so you can yell it again. Skip appears twice and means different things: at step 1 it drops the call entirely and jumps to step 3; at step 3 it saves the pitch with no spot. A no-called-location mode is still open as a pitch-setup option.
