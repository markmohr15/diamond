Turn 07 · Controls that say what they do
The entry is three steps, so the screen says so
A step rail replaces the guessing: 1 pitch type → 2 call code → 3 location, with the current step named and the finished ones showing their value. The three steps are drawn in order: 7A step 1 with nothing picked, 7B the call-code gate, 7C / 7D the location step. Location only opens once the call is confirmed. All four sit in CALL mode — calling, confirming and placing is one workflow; RECORD is the shorter path for logging a pitch you didn’t call. Skip moved out of the commit bar and became Skip location, sitting under the grid next to the thing it skips, and Cancel became Discard pitch next to the step-back. The top-bar arrow is now labelled UNDO PITCH 3 so it can’t be confused with stepping back inside this entry, and the duplicate CALL USED chip is gone — the receipt lives in the rail. 7C and 7D are the same screen; only the selected-state colour differs.
