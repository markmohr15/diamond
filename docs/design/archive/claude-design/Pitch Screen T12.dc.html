Callable spots, redrawn to §11.4 and §23.2 (replaces 11F)
11F asked how the grid re-flows for a team that doesn't have six cells. The spec answers that it never re-flows. Every team groups the same canonical 5×5. The 3×3 is always drawn. Of the 16 cells around it, only those the selected type can be called to are drawn, as one swatch the size of a zone cell, centered on the zone's target. A grouped zone is one swatch, because it is one call with one code. Grass steps: wash = callable, solid = called, dashed = off for this type.

For Mark to rule: where this turn and the spec disagree
1. The field's own controls. §15.5 (v0.54) says "the play surface carries only that ✓", with undo and cancel as a pair in the top bar. The brief asked for a bottom bar with Back one, Start play over, Leave field and ✓, and 12A follows the brief. §15.5 needs rewriting to match, or a ruling the other way.
2. "The holder wears the accent ring" (§15.1). 11B replaces the ring with a Grass fill, the ball in the rim, and a HAS BALL tag. The spec wording needs updating if that's accepted.
3. A wrong Bunt chip. If the outcome sheet's Bunt was a mis-tap, the field asks only ground/air, and there's no way back to the five. Should the pair dialog have a quiet Not a bunt exit? 12B draws it without one, per the spec.
4. The code card vs. the ✓ (§10.3). The spec puts a checkmark beside the code. 10B makes the whole code card the button. §10.3 also asks for swipe-to-re-roll on the code, and a swipe on a big tap target risks confirming by accident. Either keep 10B and move re-roll elsewhere, or go back to a ✓ beside the code.
5. Stayed on the wild-pitch prompt. The brief lists Took second, All runners up one, or go to the field. A wild pitch nobody advanced on is real: did the brief leave it out on purpose? Also, should WP/PB be hidden with the bases empty, like Stolen base?
6. Where batter side comes from in M1. With no roster, the scorer has to set it per batter. 12C makes it a standing segmented control. Is that the intended source?
7. Infield fly's home. §15.3 puts infield fly on the landing node's + chip, but the brief said the ⚾ node. 11A/12A follow the brief. One of them should change.
