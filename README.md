# Diamond

Coaching-first baseball/fastpitch scoring, pitch calling, and scouting. Tablet-first Flutter app,
offline-first, event-sourced. See `CLAUDE.md` for the working constitution and `docs/spec.md` (v0.11)
for the full specification.

## Getting started
1. Read `CLAUDE.md`.
2. `tickets/` contains Milestone 1. Start at `DIA-001`.
3. Fixtures in `fixtures/plays/` are the rules-engine acceptance suite (§14) — they must always pass.
